# Content Strategy — HGW Natural

**Principio:** autoridad + evidencia + transparencia. No producir contenido artificial.

## ESTADO BLOQUEANTE

La creación de contenido de autoridad (/evidencia, /dra-deming-li, /que-es-hgw) está **bloqueada** hasta que el owner aporte:
- Documentos de patentes (número, país, titular)
- Certificaciones reales (organismo, número, alcance)
- Perfil verificable de la Dra. Deming Li
- Documentación del plan de compensación

Sin esto, NO se debe publicar contenido que afirme estos hechos.

## Content Quality Gate (checklist obligatorio antes de publicar)

- [ ] intención de búsqueda definida
- [ ] keyword principal + secundarias
- [ ] autor identificado
- [ ] fecha de publicación/actualización
- [ ] fuentes citadas
- [ ] claims sensibles clasificados (ver claims-audit.md)
- [ ] enlaces internos (≥3 contextuales)
- [ ] CTA claro
- [ ] imágenes optimizadas con alt
- [ ] Schema válido
- [ ] meta title ≤60 / description ≤160
- [ ] URL limpia y estable
- [ ] legibilidad
- [ ] utilidad real

## Reglas de redacción

1. Diferenciar siempre "lo que afirma el fabricante" de "lo que demuestra la evidencia".
2. Nunca convertir un mecanismo teórico en afirmación médica.
3. Citar fuentes primarias; sin fuente → marcar REQUIERE_VERIFICACION.
4. Sin promesas de ingresos ni cifras de resultados.
